Необычные радиосигналы

Этот небольшой архив посвящён странным радиопередачам и сигналам, которые действительно существуют или были зарегистрированы.

Здесь нет мистических объяснений. Если происхождение сигнала неизвестно, это означает только то, что его источник не установлен.

FILE 001 — UVB-76
Частота: 4625 кГц
Диапазон: короткие волны
Тип: голосовые сообщения / повторяющийся сигнал

Радиостанция, известная среди радиолюбителей благодаря постоянному повторяющемуся звуковому сигналу.

Иногда вместо сигнала передаются голосовые сообщения с отдельными словами и числами.

STATUS: OBSERVED

FILE 002 — THE BLOOP
Год: 1997
Источник записи: NOAA

Очень мощный подводный звук, зарегистрированный системой гидрофонов в южной части Тихого океана.

Первоначально происхождение сигнала было неизвестно. Позднее NOAA связала его характеристики с крупными ледовыми процессами.

STATUS: EXPLAINED

FILE 003 — TAOS HUM
Место: Таос, Нью-Мексико
Тип: низкочастотный гул

Некоторые жители сообщают о постоянном низком гуле, который слышен внутри помещений.

Источник всех подобных сообщений не был установлен. Возможны различные объяснения, включая промышленные и акустические источники.

STATUS: INVESTIGATED

Числовые станции

Коротковолновые радиопередачи, содержащие последовательности чисел, букв или кодовых слов.

Некоторые станции известны десятилетиями. Назначение отдельных передач официально не раскрывается.

Необычные звуки

Подводные сигналы, атмосферные явления, низкочастотный гул и другие записи, происхождение которых обсуждалось исследователями.

Об архиве

Сайт создан как небольшой независимый каталог материалов о радиосигналах.

Материалы следует воспринимать критически. Неизвестное происхождение записи не означает сверхъестественное происхождение.
